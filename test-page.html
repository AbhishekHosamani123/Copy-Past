🏰 Hostile Site Simulator

This page pretends to be a website that hates your freedom. It blocks: text selection, right-click, copy/cut (Ctrl+C / Ctrl+X), paste (Ctrl+V and right-click-paste), and select-all (Ctrl+A) — using the exact same tricks real sites use (preventDefault() on events + CSS user-select: none).

How to test

  1. Extension OFF (badge shows OFF): try to select the text below, right-click, copy, or paste — every attempt shows a red 🚫 toast.
  2. Extension ON (badge shows ON, or press Ctrl+Shift+U): select the text, copy it, right-click, paste into the box. Everything just works. 🎉
  3. Toggle back OFF: the page's blockers come back instantly, no refresh needed.
